# Sistema de Agendamento Online para Barbearias

Uma solução digital moderna e eficiente desenvolvida para automatizar o fluxo de agendamentos, otimizar o tempo de atendimento e melhorar a experiência do cliente final.

---

## 💻 Sobre o Projeto

Este sistema foi projetado para substituir agendas físicas e processos manuais em barbearias. A plataforma permite que os clientes realizem agendamentos de forma autônoma, escolhendo o profissional de sua preferência e visualizando os horários disponíveis em tempo real. 

A arquitetura do projeto prioriza a leveza, segurança no tratamento dos dados e uma interface limpa e intuitiva (responsiva para dispositivos móveis).

---

## 🛠️ Tecnologias e Ferramentas

O ecossistema do projeto foi construído utilizando tecnologias consolidadas no mercado web:

* **Backend:** PHP (Arquitetura estruturada para processamento de regras de negócio e segurança)
* **Banco de Dados:** MySQL (Modelagem relacional para consistência de dados de clientes, profissionais e horários)
* **Frontend:** HTML5 e CSS3 (Design responsivo e estilização customizada focada em UX/UI)
* **Servidor Local:** Ambiente XAMPP para desenvolvimento e testes

---

## 🚀 Principais Funcionalidades

* **Autenticação Segura:** Controle de acesso para clientes e profissionais através de sistema de login e cadastro.
* **Gestão de Horários:** Evita conflitos de agenda através de validação em tempo real no banco de dados.
* **Seleção de Profissionais:** Flexibilidade para o cliente escolher o barbeiro de sua preferência.
* **Painel Adaptável:** Interface otimizada tanto para computadores quanto para smartphones.

---

## 🔧 Como Executar a Aplicação Localmente

### Pré-requisitos
* Servidor local com suporte a PHP e MySQL (Recomendado: **XAMPP**, WampServer ou Laragon).

### Passo a Passo
1.  Mova a pasta do projeto para o diretório de arquivos públicos do seu servidor (ex: `C:\xampp\htdocs\`).
2.  Inicie os serviços do **Apache** e **MySQL** através do painel de controle do seu servidor local.
3.  Importe o banco de dados utilizando a ferramenta de sua preferência (ex: *phpMyAdmin*) e certifique-se de que as credenciais em `config/conexao.php` estejam corretas.
4.  Acesse a aplicação através do navegador utilizando o endereço:
    ```text
    http://localhost/site/
    ```
